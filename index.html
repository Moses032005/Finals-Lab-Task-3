Table Manipulation

Task Description

The following are the tasks that need to be implemented using MySQL statements. Make sure to complete them in the order specified.

STEP 1: Create a table named products

With the following fields:

* id: Unique integer, auto-increment, primary key * product_name: String (VARCHAR) with a maximum length of 100, cannot be null * price: Decimal

STEP 2: Add CHECK constraint

Ensure that the price of the product must be > 0.

ALTER TABLE products ADD CONSTRAINT chk_price CHECK (price > 0);

STEP 3: Insert products

Insert the products that will not violate the check constraint:

INSERT INTO products (product_name, price) VALUES ('Laptop', 999.99), ('Smartphone', 599.99), ('Tablet', 299.99), ('Keyboard', 19.99), ('Mouse', 14.99), ('Desk Lamp', 24.99), ('Speakers', 9.99);

STEP 4: Modify product name field

Change to have a maximum length of 120 characters:

ALTER TABLE products MODIFY product_name VARCHAR(120) NOT NULL;
